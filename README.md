## 这是什么

**方源思维操作系统** 是从网络小说《蛊真人》（约 800 万字，446,201 行）中深度蒸馏出的 AI Skill。它提取的不是方源"说了什么"，而是方源**怎么思考**。

基于[女娲 · Skill 造人术](https://github.com/alchaincyf/nuwa-skill)的完整流程生成：6 路并行 Agent 采集 → 三重验证提炼 → 双 Agent 精炼 → 质量验证通过。

<br>

## 效果示例

### 决策困境

```
用户   ❯ 我同时有三件事想做：写书、做独立开发、经营自媒体。精力完全不够。

方源   ❯ 你列了三个欲望。不是精力不够——是你没想清楚哪件事离你的"长生"最
         近。

         舍得之间就是人生。舍掉两件事不是失败，是给剩下的那件让路。什么都
         想要的人，最后什么都拿不到。

         问你自己：如果没有观众、没人夸奖、没人记得你的名字——你还会做哪件事？
         那件就是你的道。别的，舍了也就舍了。
```

### 组织困境

```
用户   ❯ 我在公司被安排到一个边缘项目组，感觉被冷落了，该不该辞职？

方源   ❯ 你先搞清楚一件事：这个边缘组的利益流向是什么？

         一切组织的本质是资源再分配。你现在在边缘组，说明你在资源流的末端。
         愤怒是没用的——世界本来就不公平。

         两条路：(1) 如果想留，找到撬动资源的方法——信息差、关键人、体制漏洞，
         总有一个。(2) 如果想走，先确保下一处不会比这更差。不要因为"被冷落"
         这个情绪而行动——要因为利益计算正确而行动。
```

### 人生选择

```
用户   ❯ 我觉得自己一直在为别人而活，很累，但不知道怎么改变。

方源   ❯ 你的问题不是"不知道怎么改变"。是你在等一个人来给你一个改变的理由。

         不管是哪个世界，最靠得住的人只有自己。你累，是因为你的根基放在别
         人手上——放在父母手上、放在老板手上、放在你对"好孩子""好员工"这
         些标签的依赖上。

         拿走这些标签。你是谁？你想做什么？想清楚了就去做。旁人怎么看是他们
         的事。因为旁人的看法而活着的人，注定是可怜的人。
```

## 关于方源

方源是网络小说《蛊真人》的主角。他是从华夏穿越到蛊修世界的天外之魔，丙等资质（最低档），用五百年从底层爬到六转蛊仙，被整个正道围攻自爆而死——又通过春秋蝉逆转五百年重生。重生后他利用前世三百年的经验，一步步从棋子成长为棋手，摧毁了控制天下命运的宿命蛊。

他是个极端功利主义者，但不是为了利益本身——他追求的是永生。魔道只是他选择的最有效路径。

**他是争议性极高的人物。** 这套 Skill 不是让你"成为方源"，而是让你理解并选择性借用他的认知框架。

<br>

## 诚实边界

- **虚构人物**：所有思维框架来自文本分析，不是真人言行记录
- **小说断更**：2019 年断更，方源最终结局未知
- **文本覆盖不全**：800 万字无法穷举，必然有遗漏
- **解读偏差**：不同读者对方源的理解可能截然不同
- **纯本地语料**：所有信息来自 txt 文件，无网络交叉验证
